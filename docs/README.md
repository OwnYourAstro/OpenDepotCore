# Docs

Format and protocol notes migrate here as the corresponding code lands:

- `ADK_FORMAT.md` — `.cpg` OLE2 container, `AdkFileHeader`, record layout, ciphers.
- `RCMP_INTERNAL.md` — RCMP framing, commands, auth, write session.
- `WRITE_PROTOCOL.md` — end-to-end radio write sequence and safety rules.
- `TRUNKING_FORMAT.md` — trunking system records.
- `SAFETY.md` — write gating, backups, and recovery.

Until M1 they remain in the legacy `OpenDepot` repository under `docs/`.
